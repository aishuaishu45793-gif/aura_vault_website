## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/aishuaishu45793-gif/aura_vault_website.git
```

### 2. Open the project

```bash
cd aura_vault_website
```

### 3. Install dependencies

If the project uses npm:

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

If your project uses a different start command, use the command specified in `package.json`.
